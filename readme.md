# Premier University Chattogram — 8th Semester Repository

## Overview

This repository contains course materials, lab assignments, reports, and project files for the 8th semester at Premier University Chattogram. It is organized by subjects and assignment type to make it easier to find code, report sources, and final deliverables.

## Repository Structure

- `CC Lab/`
  - Contains multiple lab folders for the Compiler Construction course.
  - Each lab typically includes source code, LaTeX report files, screenshots, and generated PDFs.

- `CCCCS Mid/`
  - Contains midterm course materials and report source files.
  - Includes LaTeX files and document artifacts for multiple labs.

- `CCCSL Lab/`
  - Contains laboratory reports, screenshots, and LaTeX source code for the CCCSL course.
  - Organized by lab number.

- `Complex Engineering Assignments/`
  - Contains assignments on machine learning and engineering topics.
  - Includes directories for specific ML projects and supporting files.

- `Image Generation/`
  - Stores image generation assets, including prompts and generated images.
  - Includes a dedicated `Daredevil/` and `Headshot Photos/` collection.

- `ML CT 2 Decision Tree/`
  - Contains material related to the Decision Tree assignment for Machine Learning.

- `MLL Final Project/`
  - Contains the final machine learning project files.
  - Includes `cards.csv` and `PlayingCards_Classification.ipynb`.

- `PR Theory/`
  - Contains project report files and LaTeX documents for PR Theory.
  - Includes `main.tex`, Jupyter notebooks, and compiled reports.

- `PRL/`
  - Contains performance testing work.
  - Includes notebooks, trained models, and submission files.

- `PRL Project/`
  - Contains a crop disease classification project.
  - Includes `crop_disease_final.ipynb` and project notebooks.

- `Thesis and Report Templates/`
  - Stores document templates for thesis and course report generation.

## Notable Files

- `readme.md` — repository overview and navigation guide.
- `MLL Final Project/PlayingCards_Classification.ipynb` — card classification project notebook.
- `PR Theory/PR_Assignment.ipynb` — PR Theory assignment notebook.
- `PRL/Performance Test 01/PRL_C_1118_PT-1_Code.ipynb` — performance test notebook.

## How to Use

1. Browse the top-level folders to identify the course or assignment you need.
2. Open the lab folders to find source code, LaTeX files, and report outputs.
3. Use the LaTeX source files inside `*.tex` folders to rebuild reports if needed.
4. For machine learning projects, open the `.ipynb` notebooks in Jupyter or VS Code.

## Notes

- Some folders include intermediate files such as `.aux`, `.fls`, `.fdb_latexmk`, and output logs.
- If you want to regenerate reports, use the relevant `.tex` source files with a LaTeX compiler.
- The repository contains both source code and generated artifacts for easier review.
