\section*{Experiment No 04}

\section*{Experiment Name}
Write a program to match whether a given string is generated by a given pattern or not.

\section*{Objective}
The objective of this experiment is to design and implement a program that checks whether a given input string matches a specified regular expression pattern. This experiment helps in understanding pattern matching, regular expressions, and their role in lexical analysis and compiler design.

\section*{Algorithm}
\begin{enumerate}
    \item Start the program.
    \item Read the number of test cases.
    \item For each test case:
    \begin{enumerate}
        \item Read the regular expression pattern (R).
        \item Read the input string (S).
        \item Create a regular expression object using the given pattern.
        \item Match the input string against the regular expression.
        \item If the string fully matches the pattern, display ``Match Found''.
        \item Otherwise, display ``No Match''.
    \end{enumerate}
    \item Stop the program.
\end{enumerate}

\section*{Discussion}
This experiment demonstrates the use of regular expressions to verify whether a given string is generated by a specified pattern. The program successfully checks complete string matches using built-in regex libraries. This approach simplifies lexical pattern recognition and provides insight into the use of regular expressions in compiler design and text processing applications.
